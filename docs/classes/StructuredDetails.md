# Structured details

`packages/ui-widgets/src/structured-details.js` exports four presentation helpers through the package and classic `AIRPG_WIDGETS` adapter. They do not own domain data, selections, disclosure persistence or request lifetimes.

- `createDisclosure({document, summaryText = '', className = '', summaryClass = '', open = false, dataset = {}})` returns native `{details, summary}` chrome. The browser owns keyboard/open behavior; callers append their existing body and may build a rich summary. No event subscriptions, registry or synthetic tree behavior are added.
- `disclosureMarkup({...chromeOptions, bodyHtml})` serializes that same chrome and appends the host's already-rendered HTML without parsing it. This explicit trusted-body boundary preserves embedded controls/leading textarea newlines and avoids an extra render/escape pass. Titles/data attributes use native DOM escaping. The host remains responsible for safe body construction.
- `createFieldComparison({document, rows, beforeLabel, afterLabel, classNames})` renders ordered `{label, before, after, changed}` rows. Labels/values are host-formatted strings and changed is a host-computed boolean. The helper neither compares domain objects nor supplies missing/empty placeholders. Content is literal text; class mapping preserves app themes.
- `createValueProjection({document, value, formatKey, formatValue, classNames})` renders read-only native lists/definition lists/paragraphs. Both formatters return literal strings. Root absence decisions, labels, null/zero/false policy and source authority remain the host's responsibility. This is not an editable schema or JSON inspector.

Actual consumers are Chat's shared check-details adapter, grouped Turn need/disposition rows, and Stories remembered disclosures, field comparisons and source projections. Stories retains its key union/order, JSON change flags, pretty formatting and explicit accept/merge actions. Turn normalization/severity/deduplication/entity routing remains local. Direct and actual-consumer browser gates and Turn adapter units passed. The independent specimen is `examples/structured-details.js`; evidence is recorded in the [structured-reader plan](../superpowers/plans/2026-11-05-structured-reader-consolidation.md).
