# NativeSuggestions

`packages/ui-widgets/src/native-suggestions.js` exports `NativeSuggestions`; the classic controls adapter exposes `AIRPG_WIDGETS.NativeSuggestions`. It adopts an existing native input and suggestion container without replacing the host's field or token markup. CollectionView owns transient option content and releases native button listeners on replacement, hide and destruction.

`new NativeSuggestions(input, root, {getMatches, renderOption, onChoose, onError, blurDelay = 100})` requires same-document elements and four callbacks. Duplicate ownership rejects. `getMatches(trimmedQuery)` returns an array or a promise for one; matching, normalization, ordering, result limits and transport belong to the caller. `renderOption(item)` returns a native button in the owned document. `onChoose(item)` commits application state. `onError(error)` receives event-driven query/activation failures without replacing their original cause.

The owner queries on input/focus, prevents the input's Enter default and chooses the first matching option, and hides on Escape without preventing or stopping that event. Native mousedown prevents blur and commits the option. Blur hides after the configured non-negative duration, default 100ms; focusing again cancels the pending blur timer. No Arrow-key navigation, global outside handler, focus trap, native button click behavior or automatic focus return is introduced.

`refresh({chooseFirst = false})` exposes the async query operation and propagates failures to its caller. Starting a query clears the previous option buttons. Each query captures its generation and input text; results are discarded after a newer query, hide, clear/selection, destruction, detachment or disabled input. Empty queries hide immediately. A stale operation cannot render options or choose a former first match. `hide()` invalidates delivery, cancels blur, releases current option listeners and hides the root, while keeping input and selected application state intact.

`destroy()` is idempotent, aborts input listeners, cancels the timer, invalidates delivery and releases content/weak ownership. Retained former option buttons have no live owner listener. It keeps the native input/container available for a new owner; further use of the destroyed instance rejects.

The actual consumers are both Location and Region vehicle editors' current-target and fixed-route searches. They retain native markup, selected snapshots/Map order, unresolved destinations and ETA/exit rules. Their token containers compose CollectionView separately; selected domain state does not move into the suggestion owner. The package specimen exercises search/choose/hide/destroy/remount. Six focused Chromium cases and nine serializer cases passed, including direct lifecycle, real edits, stale response, pending targets and failure/retry without clearing selection.
