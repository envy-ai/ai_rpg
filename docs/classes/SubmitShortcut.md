# SubmitShortcut

`packages/ui-widgets/src/submit-shortcut.js` exports one delegated native submission
listener per document. Construct `new SubmitShortcut({document,dialogSelector =
'dialog, [role="dialog"]',canHandle = null,onError = null})`. Rebinding an owned
document rejects until its controller is destroyed. No app globals/selectors,
form state, transaction policy or rendering are imported.

`handle(event)` returns whether it handled Ctrl+Enter/Cmd+Enter. `isShortcut(event)`
is also a static predicate. Composition/default-prevented events, disabled native
controls (including disabled fieldsets), and readonly controls are ignored. Inputs,
textareas, selects and contenteditable controls keep their native behavior otherwise.
A native top-layer dialog excludes background controls. Optional `canHandle(control,
dialog,event)` supplies the host's additional custom/media priority policy.

A modal control submits its associated/nearest native form with `requestSubmit`,
using its first available submit control. Native validation and submit listeners
remain authoritative; all-disabled submitters leave the key untouched. An ordinary
page form has no automatic shortcut. `data-ctrl-enter-submit` explicitly maps a
control/ancestor to a clickable action, queried within the nearest dialog or form
(document only outside both). Missing/invalid selectors throw clear errors with
original causes, and disabled/aria-disabled actions do not consume the key. There
is no unrelated-action or implicit `.click()` substitute for form submission.

The owned bubble listener forwards errors to `onError` when supplied; direct
`handle` calls throw. Successful handling prevents default/stops bubbling after
existing target handlers have had a chance to consume the event. `destroy()`
aborts the listener, releases registry/references and is idempotent. Further
handling rejects; a new controller can adopt the same document.

`client/widget-adapters/modal-submit-shortcuts.js` retains the existing application
URL/global `AIRPGModalSubmitShortcuts.handleModalCtrlEnter/isCtrlEnterShortcut`.
It adds existing app dialog-class aliases, top custom/media/native priority and
original-error PageFeedback reporting. Shared head load order places it after its
app dependencies. Cached pagehide keeps the binding; final unload disposes it.
`public/js/modal-submit-shortcuts.js` is generated by widgets:build, with no runtime
fallback or Node-only fake-DOM branch. The independent specimen uses only native
forms/dialogs and the package helper.
