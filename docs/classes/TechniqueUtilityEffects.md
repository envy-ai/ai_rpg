# TechniqueUtilityEffects

`TechniqueUtilityEffects.js` implements `teleport`, `summon`, and `resurrection` in the shared technique transaction. The service owns checks, costs, commit, and receipt replay.

Teleport uses a fixed `destinationId` or `utilitySelections[effect.id].destinationId`, targeting a living local actor and moving it to an existing different location through native `Player.setLocation`. An individual party NPC leaves through native party removal. An area effect including that NPC and the player retains membership; player movement carries the party. Native player arrival and visit data is rolled back with the transaction.

Summon uses `summonMode: "existing" | "template"` and positive integer `lifetimeMinutes`. Existing actors must be available living remote NPCs outside the party and another active summon. Template mode uses saved `templateId`, a selected saved template ID, or an inline typed `template` with `name`, `description`, optional `shortDescription`/`class`/`race`/`gender`, required positive integer `level`, required finite `attributes` and nonnegative integer `skills` maps, and optional positive `health`. Inline templates omit engine-owned IDs and install only on a successful cast. Same-name saved templates are reused only if their typed fields match exactly. Each cast gets a new actor ID, empty inventory/gear, zero XP/currency, and no learned techniques.

Resurrection uses positive authored `health` (numeric amount or formula resolved by the service), targeting an existing dead local actor. Native setters restore health and clear only intrinsic `Deceased`/`Incapacitated` statuses and corpse countdown. Other status, inventory, and XP state remains. Removed corpses cannot be targeted.

`prepareEffect` returns a JSON-safe plan; `assertCurrent` rejects stale world facts; `applyEffect` returns a serializable mutation receipt and synchronous undo closure. `validateReceipt` checks historical utility mutations without live actor lookup. The helper exposes privacy-filtered known destinations, previously seen remote actors, saved templates, and dead local targets for prompt context.

`techniqueSummons.json` stores `{ version: 1, templates: [], active: [] }`; absent legacy state is empty, malformed present state rejects. Active leases identify actor, source/template, destination, origin for recalled actors, expiration world minute, and operation. `Globals.advanceTime` expires due leases deterministically, including dead or party actors. Existing actors return to origin. Template actors drop ordinary inventory and barter stock acquired after summoning at their current location, clear barter ownership through the native Player method, and unregister. Party members first leave through the native party API. Corpse cleanup leaves active leases for their authored lifetime; intentional actor unregister cancels the lease. Expiry never grants XP or generates loot. Missing required world references raise explicit errors. `setActorRegistry` binds the server's live `players` Map so spawned actors participate in ordinary saves. Unplaced actors receive empty location-dependent prompt facts during starting character authoring.
