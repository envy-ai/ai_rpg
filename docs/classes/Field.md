# Native fields

`packages/ui-widgets/src/field.js` exports `createField` and `serializeField`; the classic controls adapter exposes both under `AIRPG_WIDGETS`. Native field construction is shared by calendar/status forms, editable domain rows, allocator attribute controls, mod scalar fields and Stories typed scalar rendering. Domain validation and persistence stay with their adapters.

`createField({document = globalThis.document, label, className = '', inputClass = '', type = 'text', value = '', rows = 2, placeholder = '', step, id})` returns `{field, input, label}`. It creates a wrapper, associated visible label and native input/textarea/select. Null/undefined become empty; explicit zero and false retain their scalar text. The caller supplies select options, checked state, validation attributes, readonly/disabled policy and any compact-control placement. Omitted DOM IDs use a local counter; this does not allocate persisted game identities.

`serializeField({field, input})` returns HTML for a clone containing exactly that native control. It reflects current input value, checkbox/radio checked state, textarea text and every option's selected state. It preserves wrapper/label/control attributes and safely relies on DOM HTML escaping. A leading textarea newline receives the extra initial newline consumed by HTML parsing. The original control's live state and reset defaults remain untouched. Callers append options and explicitly select the desired value before serialization; setting a select's value before adding options is insufficient.

The helper rejects foreign/non-native/multiple-control fields. A nonempty single select with selectedIndex -1 cannot round-trip its unselected state in HTML: provide an explicit blank/current-value option. File selections and indeterminate checkboxes also cannot round-trip in HTML and reject; retain their live controls. These are representation errors, not new domain validation. Empty selects and multiple selects can represent no selection.

Stories uses createField plus serialization for native scalar, option, checkbox, nullable and string-list markup while keeping its recursive reviewed-document renderer and delegated handlers. The standalone specimen serializes edited native fields into a detached template and displays the round-tripped values. Direct round-trip and actual Stories reviewed-field/regression browser cases passed; verification is recorded in the [weather and typed field plan](../superpowers/plans/2026-11-05-weather-typed-field-consolidation.md).
