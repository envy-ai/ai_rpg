[master ledger](2026-11-05-ui-widget-merge-master.md). All C01–C48 and M01–M18 rows

accounts for every original family, all 64 static root/backdrop names and runtime
overlay groups. Historical plans remain the implementation record; this matrix
and the final master checkpoint state current acceptance. Source references use
function names because old audit line numbers move.

`Native/domain` requires the stated semantic distinction, not a filename exemption;
No open migration/evidence gate remains in this matrix. Shared behavior does not prove every
feature transaction. Existing accepted evidence remains usable only while its
relevant inputs remain unchanged. A test file's existence is not a passing result.
